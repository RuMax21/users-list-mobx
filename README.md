# Users Dashboard

A simple React application for managing users: fetching, viewing, editing & deleting user data.

## Features

- Fetch random user from API
- Display users in a table
- Delete users
- Edit user data
- Form validation

## Tech Stack

- React
- TypeScript
- Mobx
- TanStack Table
- React Hook Form
- SCSS Modules
- Axios

## Installation & Run

```
git clone https://github.com/RuMax21/users-list-mobx.git
cd users-list-mobx
npm install
npm run dev
```

## Environment Variables

Create a .env file:

```
VITE_API_URL=https://api.api-ninjas.com/v2
VITE_API_KEY=YOUR_API_KEY
```
